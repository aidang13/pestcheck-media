# PestCheck media

Finished short videos for PestCheck's social accounts (TikTok, Instagram, YouTube @pestcheckapp),
hosted here so the Metricool scheduler can fetch them by URL.

Files: `videos/<YYYY-MM-DD>-<slug>.mp4`, served at
`https://aidang13.github.io/pestcheck-media/videos/<file>`.
